## Review

Codex could not run (usage limit until 17 Nov 2026). A security reviewer agent with no build notes read the code and the spec and found 8 issues:

1. High. A force-added `.codehere/local/approvals.json` arrives through `git pull` and approved a command. Approvals moved to `~/.config/codehere/approvals.json`.
2. High. File names and state values reached a shell through `git()`. `git()` now takes an argument array, and state values must be commit ids.
3. High. A git author name could carry terminal escapes into the approve prompt. `printable()` escapes control, C1, bidi and zero-width characters.
4. Medium. An agent can fake a terminal with `script` and approve. Accepted; an approval made during the session is shown to the developer.
5. Medium. Permission rules saved in `.claude/settings.local.json` were reported as settings changes. Only the `hooks` and `disableAllHooks` keys are watched now.
6. Low. After the 3-block cap the settings line was dropped.
7. Low. No settings snapshot when SessionStart did not run. The first prompt takes one.
8. Low. `testTimeoutSeconds: 0` meant no timeout. The minimum is now 1 second.

Found while fixing 2: a forged `startHead` such as `--output=<file>` reached git as an option. Fixed by the same commit-id check.

## Second review (26 Oct)

A fresh security reviewer agent read the final diff. 8 findings, all now fixed or written down:

1. Medium. Committed settings can set `XDG_CONFIG_HOME` or `HOME` for hooks; a relative or in-repo value put the approvals file inside the repo, where a teammate can write it. Fixed: `XDG_CONFIG_HOME` is used only when absolute, an approvals path inside the repo is refused, and `env` in `.claude/settings*.json` is now watched. Whether Claude Code passes project `env` to hooks was not checked; the fix does not depend on it.
2. Medium. A file named `:(exclude)*.test.js` was read by git as a pathspec and hid a weakened test. Fixed: `git --literal-pathspecs`.
3. Medium. A force-added `state.json` of the wrong shape made every hook fail open, silently. Fixed: it counts as empty.
4. Low. A resumed session reported the developer's own changes made while it was closed. Fixed: settings are re-read on resume.
5. Low. A hook removed in a session that ends without a finish check is never reported. Written in the README limits.
6. Low. `printable()` missed format, filler and variation characters. Fixed: all of `\p{Cc}` and `\p{Cf}` plus those ranges.
7. Low. `verifyOnStop` and `testTimeoutSeconds` are not covered by the approval. Written in the README limits; `codehere status` now shows a check a teammate turned off as off.
8. Low. The session-start note repeats the test command to the agent, as rules already are. Accepted under threat T3.
