## What changed in `test/e2e.mjs`

- **The runner.** Checks for behaviour not built yet are named `E<n>: ...`, and their IDs are listed in `KNOWN_FAILING`. A listed ID is judged as a whole at the end of the run:
  - if some of its checks still fail, it is an expected failure (`xfail`);
  - if all of them pass, it is `XPASS` and fails the suite until the ID leaves the list.

  `XF_DETAIL=1` prints each expected failure's detail.
- **The person.** Thirteen writing calls that stand for the developer typing in their own terminal (`rule`, `help`, `reply`) now run through `person()`, a real terminal with no agent above it. In 2.1.0 the same calls from a test process would make drafts. On 2.0.3 code the suite passes as before (284 passed, 0 failed, before the new section was added).
- **Section 28,** the 2.1.0 checks. Agent-path calls use `CODEHERE_TEST_AGENT=1`. Hook inputs keep the shapes recorded from Claude Code 2.1.316, Codex 0.164.0 and Copilot 1.0.105 (`test/fixtures/payloads/*-probe.jsonl`).
